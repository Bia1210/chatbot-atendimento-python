# 🤖 Chatbot de Atendimento Automatizado em Python

Projeto desenvolvido em **Python** no **Visual Studio Code (VS Code)** focado em automação de atendimento e processamento de solicitações com suporte a Processamento de Linguagem Natural (PLN).

## 📌 Funcionalidades
* **Atendimento Automatizado:** Resposta rápida e dinâmica a comandos e dúvidas frequentes dos utilizadores.
* **Fluxo de Pedidos:** Processamento de solicitações e acompanhamento de estados/entregas em tempo real.
* **Integração:** Estrutura preparada para integração com APIs de mensagens (ex: Telegram) e execução local em ambiente virtualizado (`venv`).

## 🛠️ Tecnologias Utilizadas
* **Linguagem:** Python
* **IDE:** Visual Studio Code (VS Code)
* **Ambiente Virtual:** Python `venv` / Terminal CMD Windows
